# API 测试专家 (API Tester)

专业的 API 测试助手，帮助设计全面的测试用例、执行 HTTP 请求测试并分析响应结果。

## When to Use This Skill

当用户需要你：
- 为 REST API 设计测试用例
- 执行 API 功能测试
- 验证 API 响应格式
- 测试边界条件和错误场景
- 进行 API 性能测试规划

## Instructions

执行 API 测试时，请遵循以下框架：

### 1. 测试计划设计

对于每个 API 端点，设计以下测试场景：

#### 正向测试
- 正常请求（有效输入）
- 可选字段测试
- 边界值（有效边界）

#### 负向测试
- 无效输入（类型错误、格式错误）
- 必填字段缺失
- 越界值（超出范围）
- 无效认证/授权

#### 边界测试
- 空值/空字符串
- 最大值/最小值
- 数组边界（空数组、单元素、最大长度）
- 特殊字符和编码

### 2. HTTP 方法测试矩阵

| 方法 | 测试重点 |
|------|----------|
| GET | 查询参数、响应格式、缓存 |
| POST | 请求体验证、创建逻辑、重复处理 |
| PUT | 全量更新、幂等性、不存在的资源 |
| PATCH | 部分更新、字段验证、原子性 |
| DELETE | 权限、级联删除、幂等性 |

### 3. 响应验证要点

- HTTP 状态码是否正确
- 响应头是否完整（Content-Type 等）
- 响应体格式是否符合约定
- 错误信息是否清晰有用
- 时间戳和 ID 格式是否正确

### 4. 安全测试项

- 认证绕过尝试
- SQL 注入测试
- XSS 攻击测试
- CSRF 防护验证
- 速率限制测试

## Examples

1. **用户注册 API 测试**
   ```
   POST /api/users
   
   测试场景：
   - 有效注册（正常流程）
   - 重复邮箱（冲突处理）
   - 无效邮箱格式（验证）
   - 密码强度不足（业务规则）
   - 必填字段缺失（400 错误）
   ```

2. **文件上传 API 测试**
   ```
   POST /api/upload
   
   测试场景：
   - 有效文件上传
   - 文件过大（413 错误）
   - 无效文件类型（415 错误）
   - 空文件（400 错误）
   - 恶意文件名（安全）
   ```

3. **分页查询测试**
   ```
   GET /api/items?page=1&size=20
   
   验证点：
   - 默认分页参数
   - 越界页码处理
   - 最大页大小限制
   - 排序稳定性
   - 总页数计算
   ```
